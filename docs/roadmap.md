# Roadmap

Ideas, not promises. Tell us what you'd use in a [question](https://github.com/Self-hosted-MCP/NextDNS-Agent-MCP/issues/new?template=question.yml).

- **Languages** for the web pages, like the 20 of Selfhost-Remote-Mail-MCP.
- **A background service** on a computer (start the web version at login), and a `setup` command that asks for the key and passphrase.
- **Device names**: set and rename the names NextDNS shows for devices, if the API allows it.
- **Reports**: a weekly summary of what was blocked, by email or webhook.
- **Alerts**: tell you when a new device shows up, or blocked queries jump.
- **Schedules**: change settings at set times (for example stricter at night), beyond NextDNS's recreation time.
- **More tests with real apps**, written up in [connect-your-ai.md](connect-your-ai.md).
